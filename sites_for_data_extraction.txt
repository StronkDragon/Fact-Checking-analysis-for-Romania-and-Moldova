**2. Google Fact Check Claim Review API**
Google indexează verificările de fapte conforme standardului semantic `ClaimReview` (Schema.org). Dacă site-urile (precum AFP sau Factual) folosesc acest markup:

* Poți interoga gratuit **Google Fact Check Tools API** specificând limba română (`languageCode=ro`).
* Primești direct structura JSON standardizată (conține autorul declarației, textul, data și verdictul).

**Standardizarea schemei tale de date**

Fiecare site folosește propriile etichete pentru verdicte (ex: *Fals, Parțial Fals, Trunchiat, Fără Acoperire, Adevărat*). Pentru a aduce datele la un format unitar (precum exemplul tău în 6 clase), creează un dicționar de mapare:

```python
VERDICT_MAPPING = {
    "adevarat": "true",
    "partial adevarat": "mostly-true",
    "trunchiat": "half-true",
    "fara acoperire": "mostly-false",
    "fals": "false",
    "minciuna gogonata": "pants-fire"
}

```
